## 🧭 About me

I started as a sysadmin and became a developer because the job needed it. Every project below began as a real request: a form that needed four signatures, a room that got double-booked, a password reset at an awkward hour.

I build tools the way I'd want to receive them as an administrator:

- **On-premises first.** Installs on a single Windows Server and works on an isolated intranet. Nothing calls home.
- **Directory sign-in.** People log in with the Windows account they already have, with roles from AD groups.
- **Everything audited.** Sign-ins, approvals and admin actions are logged with user and client IP.
- **Secure by default.** Least-privilege service accounts, encrypted secrets, rate limiting, and startup checks that refuse unsafe configuration.

📍 Gujarat, India · 🎓 Diploma in Cyber Security (GFSU) · 🛡️ Certified Ethical Hacker (CEH)
